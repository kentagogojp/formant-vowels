# 母音工房（formant-vowels）

声の高さ F0 と、フォルマント F1・F2（追加で F3）の周波数を動かして、日本語の「あいうえお」をブラウザで合成するアプリです。

- インストール不要。`index.html` をブラウザで開くだけで動きます。
- 音はブラウザ標準の Web Audio API で、ソース・フィルタ方式（声門パルス＋直列フォルマント共振器）で作っています。

## 操作
- 「鳴らす」ボタンまたは Space キーで再生・停止
- 「あいうえお」ボタン（キーボードの A I U E O）で代表値に移動
- F1-F2 母音図をドラッグ、またはスペクトルの●をドラッグしてフォルマントを移動
- スライダーと数値入力で細かく調整
